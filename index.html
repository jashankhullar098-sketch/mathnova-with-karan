Sets

A set is a well-defined collection of distinct objects.

Quadratic Equation

A quadratic equation is generally written as: ax² + bx + c = 0, where a ≠ 0.

Discriminant

For ax² + bx + c = 0, D = b² − 4ac.

Important Identity

(a + b)² = a² + 2ab + b²
